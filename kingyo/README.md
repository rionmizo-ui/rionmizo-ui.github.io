- SPRITES_API.md … 描画関数の取り決め（引数・(x,y) の意味）
- DEATHS.md … 死因49種の文字リスト
- ref/ … 今のデザインの画像（カード49枚・アイコン49・死に際のコマ49種・金魚のポーズと表情・お客さんと小物・かざり16段・実際の画面）

- game.html / sample.html … 今の公開版（縮小）、*.full.html は読みやすい版
