## B. 画像をそのまま使う（R2）
ユーザーが作った「各死因の最終的な見た目」。assets/ にゲームの大きさに縮めたドット絵がある（元画像は ref_target/final/）。
**この絵をそのまま使って、死に際の動き（最後の数コマ・カード・アイコン）を作る。金魚の色6種（normal lime pink yellow sky purple）の色ちがい版も作る**（オレンジ系の色を各色のパレットに置き換え。輪郭・白目・唇・クリーム色のお腹は変えない）。

| assets | 使い道 |
|---|---|
| giant.png | 巨大化（A1）の最終の見た目 |
| overeat.png | 食べすぎ |
| possessed_ghost.png | おばけになった（金魚のおばけ） |
| skeleton.png | 空腹でスケルトン |
| fishman.png | 魚人なのに溺死 |
| split.png | 分裂失敗 |
| dragon.png | 竜になった |
| loach_fish.png | ドジョウ（お客さん）の見た目。A10 の演出にも使う |
| catfish.png | ナマズ（お客さん）の見た目 |
| turtle.png | ミドリガメ（お客さん）の見た目（おどろき顔。ふだんの顔は目を少し細くしてよい） |
| tanishi_sheet.png | **タニシ**（今の巻貝のお客さんを置き換え）。24px 幅×8コマ：0〜3 歩く、4 びっくり、5 首をすくめる、6 殻にこもる（ふた）、7 顔を出す |

- 描き方：画像を build2.js で data URI として埋め込み、起動時に読み込んで canvas にする（imageSmoothingEnabled=false）。色ちがいは起動時に1回だけ作ってキャッシュ。読み込み前は今の手描きの絵を出す
- 動き：最終の見た目へ「変わっていく」コマは、今の dieSeq の流れの最後をこの絵に置き換える／つなぐ（拡大・揺れ・まばたき程度の動きをつける）
